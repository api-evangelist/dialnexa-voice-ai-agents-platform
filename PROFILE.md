## APIs

- **DialNexa REST API** — REST API to build, deploy, and monitor AI voice agents: create agents, trigger calls, manage batch calls and workflows, work with catalog resources (LLMs, languages, voices, transcribers), manage webhooks, and connect phone numbers. OpenAPI 3.0 contract with ~54 operations across 41 paths. Bearer token authentication. (`https://api.dialnexa.com/v1`)
- **DialNexa MCP Server** — Hosted MCP server (Streamable HTTP) exposing named tools to inspect and manage DialNexa resources including Agents, Calls, Batch Calls/Campaigns, Workflows, Knowledge Base, Phone Numbers, Reference Data, Templates, Billing, Webhooks, Organization, and Dashboard. Authenticates via OAuth 2.1 (PKCE) or API key with scopes mcp:read, mcp:write, offline_access. (`https://api.dialnexa.com/v1/mcp`)
